# Calderas RPV: imágenes y prototipos

Esta carpeta reúne seis imágenes adaptadas para la web y tres propuestas para revisar la presentación de las calderas. Las fichas originales permanecen en `Contenido/calderas/`.

Para comparar las propuestas, abre `prototipos/index.html` en un navegador. Las páginas se pueden abrir directamente desde el disco y no requieren instalación.

Los precios, tiempos y consumos se transcribieron de las fichas originales. Confirma su vigencia y las condiciones de operación antes de publicar. Las ilustraciones de productos son referenciales. La imagen sobre la solicitud de patente indica una solicitud presentada; no certifica una patente concedida. La imagen de la guía es una portada y enlaza a la guía original completa.

Estas propuestas son una revisión visual independiente; no modifican la página de producción.

## Imágenes y criterios utilizados

- `imagenes/caldera-tipo-a.webp`, `caldera-tipo-b.webp`, `caldera-tipo-c.webp`: rediseños de las fichas originales con composición horizontal, paleta azul marino y naranja, tipografía legible y la ilustración original como referencia. Se mantuvieron los precios y los datos declarados para cada modelo.
- `imagenes/guia-caldera.webp`: portada para enlazar a la guía original, sin sustituir sus instrucciones de uso y seguridad.
- `imagenes/solicitud-patente.webp`: pieza informativa basada en la solicitud presentada ante INAPI; no reproduce formularios oficiales ni afirma una concesión.
- `imagenes/terraza-caldera.webp`: edición de la imagen original de terraza, conservando la escena y mejorando la luz y los tonos.

Las piezas se crearon con la herramienta integrada de generación y edición de imágenes. Se solicitó conservar la forma de las calderas de referencia, evitar datos y elementos inventados y optimizar la jerarquía visual para la web. Las imágenes WebP son versiones comprimidas de las piezas resultantes.
