# Diagnóstico local RPV — [FECHA]

Este esquema define el contenido del informe. Renderízalo con las reglas de
`html-output.md`; no dejes los marcadores entre corchetes en el archivo final.

## Alcance

Indicar que se revisó únicamente `DESARROLLO/Web` y `http://localhost:8000`.

## Resumen ejecutivo

5-10 líneas orientadas a decisión.

## Score local

Puntaje /100 y desglose: conversión, contenido/fichas, SEO on-page, UX y
accesibilidad, calidad técnica, analítica implementada y arquitectura.

## Top 5 hallazgos

Para cada uno: severidad, estado, evidencia local, impacto, esfuerzo y acción.

## Matriz de fichas de producto

Evaluar Tinajas, Calderas y Estufas: cotización/precio, especificaciones, qué
incluye, instalación, despacho, garantía, FAQ, CTA, evidencia técnica y
productos complementarios. Usar Sí / Parcial / No / No verificable localmente.

## Backlog priorizado

Listar acción, impacto (1-5), esfuerzo (1-5) y horizonte de 7, 30 o 90 días.

## No verificable localmente

Separar producción, conversiones reales, tráfico, Search Console, Core Web
Vitals de campo, stock, ventas, reseñas y cumplimiento documental externo.

## Tres acciones inmediatas

Cerrar con la acción, la métrica a instrumentar y el resultado esperado.

## Cuadro resumen de hallazgos

Esta debe ser siempre la última sección del diagnóstico. Usar una tabla con las
columnas: Estado, Hallazgo, Evidencia local, Prioridad y Siguiente acción.
No agregar contenido después de este cuadro.
