# Captura de la solicitud de patente

`solicitud-patente-captura.pdf` contiene datos personales y del trámite. Es una
captura, no el expediente completo. Se conserva aquí únicamente para revisión
local y no debe publicarse sin revisar su contenido con el responsable.

El flujo `scripts/preparar-produccion.ps1` excluye las carpetas `docs` del
paquete de producción. El enlace de la página solo aparece en localhost. Para
publicar una copia revisada en el futuro, esa decisión y su ubicación deben
definirse explícitamente con el responsable.
